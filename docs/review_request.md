# OpenSees-MCP 시스템 리뷰 요청

## 1. 시스템 개요

**목표:** 사용자가 자연어로 구조물을 설명하면, LLM이 파싱하여 구조해석을 수행하고 결과를 시각화하는 시스템

**기술 스택:**
- 해석 엔진: OpenSeesPy (FEM)
- 설계기준 DB: Supabase (KDS 41 12 00 / 17 10 00, 712건 하중 파라미터 + 2290건 지역별 위험도)
- 프론트엔드: Streamlit (고급 UI) + FastAPI (REST API/HTML 폼)
- AI 통합: Claude API (자연어 파싱), MCP Server (Claude Desktop 연동)

## 2. 해석 기능

### 지원 해석 유형

| 유형 | 엔진 | 요소 | 자유도 | 상태 |
|------|------|------|--------|------|
| 단순보 | OpenSeesPy | elasticBeamColumn | 3-DOF (2D) | 완료 |
| 연속보 | OpenSeesPy | elasticBeamColumn | 3-DOF (2D) | 완료 |
| 2D 프레임 | OpenSeesPy | elasticBeamColumn | 3-DOF (2D) | 완료 |
| 3D 프레임 | OpenSeesPy | elasticBeamColumn | 6-DOF (3D) | 완료 |
| 건물 자동해석 | 3D 프레임 + KDS 하중 | 6-DOF (3D) | 완료 |

### 3D 프레임 해석 상세

- **입력:** 층고(m) × X경간(m) × Y경간(m), 단면(KS H형강 DB), 재료(SS275/400/SM490)
- **하중 유형:** floor(선하중), floor_area(면적→분배), lateral_x/y(횡하중), nodal(절점하중)
- **경계조건:** 고정/핀 지점, 강체 다이어프램(선택)
- **출력:** 6-DOF 절점변위, 12성분 요소력, X/Y 층간변위각, 반력
- **하중조합:** 선형중첩 (KDS §1.7 기반 18개 자동생성 가능)
- **서브요소 분할:** 부재당 4개 (기본값, 조절 가능)

### 건물 자동해석 파이프라인

```
[IFC 파일] or [JSON Config]
  → BuildingModel (중간 표현)
  → LoadGenerator (KDS DB 조회)
    → DL: 슬래브자중(24×t) + 마감재 + 설비(0.5 kN/m²)
    → LL: 용도별 DB 조회 (15개 용도)
    → EQX/EQY: 등가정적해석법 (z, Fa, Fv → Cs → V → Fx 분배)
    → WX/WY: V₀ → qz × Gf × Cp × 면적
    → 18개 하중조합 자동생성
  → analyze_frame_3d_multi()
  → 결과 시각화
```

## 3. 입력 방식 (3가지)

### A. Streamlit GUI 입력 (Building Analysis 페이지)
- 사이드바에서 파라미터 직접 설정
- 경간 수/폭, 층별 높이/용도/슬래브 두께
- 단면 드롭다운 (28종 H형강)
- 지역(20개 도시), 지반(S1~S5), 중요도(특/I/II), 내진시스템(10종)
- 실시간 3D 형상 미리보기 (해석 전)

### B. 자연어 채팅 입력 (Chat Analysis 페이지)
- 3단계 워크플로우:
  1. **Phase 1 (형상):** IFC 업로드 또는 자연어 → Claude가 기하학적 파라미터 추출
  2. **Phase 2 (용도/환경):** 자연어 → 용도, 지역, 단면, 내진시스템 설정
  3. **Phase 3 (해석):** 자동 하중생성 → 3D 해석 → 결과 표시
- 예: "1~3층 사무실, 4층 식당, 서울, 기둥 H-400x400"
- Claude Sonnet 4 사용

### C. MCP Tool (Claude Desktop)
- `analyze_frame_3d`, `analyze_building` 등 MCP tool 호출
- Claude Desktop에서 자연어로 직접 해석 요청 가능
- JSON 결과 + HTML 리포트 자동 생성

## 4. 결과 시각화

### Streamlit 앱 (6개 탭)

| 탭 | 내용 | 시각화 방식 |
|----|------|-------------|
| **3D Model** | 미변형 형상, 부재 타입별 색상 (기둥:파랑, 보X:빨강, 보Y:초록) | Plotly Mesh3d (사각 프리즘) |
| **Deformed Shape** | 변형 형상 오버레이, 배율 슬라이더(1~200x), 하중케이스 선택 | Plotly Mesh3d |
| **Story Drift** | X/Y 방향 층간변위 수평막대, 허용치(1/200) 기준선, 1/N 표기 | Plotly Bar |
| **Member Forces** | 부재력 성분 선택(My,Mz,N,Vy,Vz,T), 부재력 크기 색상매핑 | Plotly Mesh3d (RdYlBu) |
| **Load Report** | DL/LL/EQ/Wind 분류별 하중 상세, 밑면전단력, 설계계수 | 텍스트 + JSON |
| **Summary** | Envelope 테이블 (전 조합 최대값), 반력 테이블 (6성분) | Pandas DataFrame |

### HTML 리포트 (MCP/독립 사용)

| 탭 | 내용 |
|----|------|
| **3D View** | 7개 요약 카드 + Plotly Scatter3d (미변형+변형 오버레이) |
| **Story Drift** | 허용치 선택(1/200~1/400) + Pass/Fail 판정 + 막대그래프 + 테이블 |
| **Reactions** | 반력 테이블 (6성분) + 합계 |
| **Model Info** | 건물 형상, 단면, 재료, 하중케이스 목록 |
| **Export** | CSV 다운로드 (변위/반력/drift) + PNG 스크린샷 |

### FastAPI 웹앱 (보/프레임용)

| 해석 유형 | 결과 |
|-----------|------|
| 단순보 | 변위도, SFD, BMD, 처짐검토 (L/300), 인터랙티브 HTML |
| 연속보 | 다경간 변위/SFD/BMD, 힌지 지원, 인터랙티브 HTML |
| 2D 프레임 | 다층/다경간 해석, 하중조합, 부재력 다이어그램, 인터랙티브 HTML |

## 리뷰 요청 사항

아래 관점에서 평가를 부탁드립니다:

1. **실무 활용성:** 실제 구조설계 실무에서 이 시스템이 유용한 단계는 어디까지인가? (개념설계? 기본설계? 실시설계?)
2. **기능 우선순위:** 현재 한계점 중 실무적으로 가장 먼저 보완해야 할 기능은?
3. **검증 신뢰도:** Midas Gen 비교 결과(8% 이내)가 실무에서 수용 가능한 수준인가?
4. **결과 표현:** 시각화/리포트에서 실무자가 반드시 확인하는데 빠진 정보가 있는가?
5. **차별화 포인트:** 기존 상용 소프트웨어(Midas Gen, ETABS 등) 대비 이 시스템만의 장점은 무엇이 될 수 있는가?
6. **위험 요소:** 이 시스템을 실무에 사용할 때 주의해야 할 구조공학적 위험 요소는?
