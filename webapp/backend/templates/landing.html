01 · Why it exists

정형 입력만으로는
구조해석을 빠르게 시작할 수 없습니다.

자연어로 의도를 받고, 자동으로 하중과 조합을 만들고, 한국어 보고서까지 한 사이클로 이어져야 합니다.

  • 01 / Repeated input

    매번 같은 모델을
    다시 만듭니다.

    자연어 입력 없이 GUI에서 층 · 경간 · 단면을 반복 입력합니다.

  • 02 / License lock

    상용 SW 라이선스에
    묶입니다.

    Midas · ETABS 없이는 KDS 검토 자동화가 어렵습니다.

  • 03 / Output gap

    결과가 보고서와
    단절됩니다.

    해석 출력을 한국어 구조계산서로 정리하는 단계가 빠집니다.

02 · Features

엔지니어가 검증해야 할 곳에
집중하도록.

자연어 입력부터 KDS 보고서까지, 반복 단계를 LLM과 오픈소스 솔버가 잇습니다.

01 — Natural language

"1층 근생, 2~5층 오피스,
서울 강남" 한 줄을 Config로.

자연어 → BuildingIntent → MCP resolve_building_config. 38개 회귀 테스트로 검증된 매핑.
